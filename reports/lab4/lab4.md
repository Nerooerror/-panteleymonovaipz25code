## 1. Фрагмент коду власних функцій
```php
// Функція для форматування та обрізання довгих заголовків
function formatTitle($text, $maxLength = 20) {
    if (mb_strlen($text, 'UTF-8') > $maxLength) {
        return mb_substr($text, 0, $maxLength, 'UTF-8') . '...';
    }
    return $text;
}

// Функція для визначення привітання за поточним часом
function getCurrentGreeting() {
    $hour = (int)date('H');
    
    if ($hour >= 6 && $hour < 12) {
        return "Доброго ранку";
    } elseif ($hour >= 12 && $hour < 18) {
        return "Добрий день";
    } elseif ($hour >= 18 && $hour < 24) {
        return "Добрий вечір";
    } else {
        return "Доброї ночі";
    }
}```

## 3. Відповіді на контрольні запитання

* **Поясніть принцип “DRY” (Don’t Repeat Yourself) та як власні функції допомагають його дотримуватись.**
  DRY — це правило, яке означає, що краще уникати дублювання однакового коду. Власні функції допомагають цього досягти через написання логіки один раз усередині функції для подальшого виклику її там, де треба

* **Що таке аргументи функції та що таке параметри за замовчуванням? Наведіть приклад з коду.**
  Аргументи — це дані, які передають у функцію при її виклику. 
  Параметри за замовчуванням — це значення, які функція бере автоматично, якщо під час виклику їй нічого не передали 
  (наприклад, $maxLength = 20 у функції обрізання тексту лабораторки)

* **Що станеться, якщо у функції не написати конструкцію return, але спробувати присвоїти результат її виклику в змінну x ($x = myFunc())? Яке значення буде в $x?**
  Якщо у функції немає return, вона нічого не повертає програмі. У такому разі змінна, якій спробували присвоїти результат її роботи, отримає значення NULL

* **Що таке “область видимості” (scope) змінної? Чи можна у тілі функції звернутись до $taskTitle, створеної за межами цієї функції, без ключового слова global?**
  Область видимості — це зона видимості змінної доступної в коді. 
  Змінні всередині функції є локальними і «не бачать» те, що створено зовні, тому безпосередньо звернутися до глобальної змінної всередині функції без ключового слова global не можна.

* **Для чого призначена вбудована функція substr() і які вона умовно приймає аргументи?**
  Вона потрібна для того, щоб вирізати частину рядка. 
  Умовно приймає саму стрічку, початковий індекс, з якого починати, і бажану довжину шматка. (для кирилиці mb_substr)
