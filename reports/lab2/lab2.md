## 1. Фрагмент коду 
```php
<?php
$appName = "Task Manager";
$taskTitle = "Вивчити основи PHP";
$taskTimeEstimate = 3;
?>
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title><?= $appName ?></title>
</head>
<body>
    <header>
        <h1><?= $appName ?></h1>
    </header>
    <main>
        <h2>Список завдань</h2>
        <ul>
            <li>Завдання: <?= $taskTitle ?></li>
            <li>Очікуваний час: <?= $taskTimeEstimate ?> год.</li>
        </ul>
    </main>
</body>
</html>
```

## 3. Відповіді на контрольні запитання

* **Що таке динамічна типізація і як вона працює в PHP?**
  Це тип типізації, при якому змінна не має заздалегідь закріпленого типу, він визначається автоматично під час виконання програми залежно від присвоєного значення і може змінюватися 

* **Як правильно розпочати і закрити блок з PHP-кодом всередині HTML-документа?**
  За допомогою тегів відкриття <?php та закриття ?>

* **В чому різниця між записами <?php echo $var; ?> та <?= $var ?>?**
  Між ними немає різниці в результаті. Другий варіант (<?= $var ?>) — це просто короткий запис першого, він зручніший і швидший для виведення змінної на екран.

* **Які основні (скалярні) типи даних підтримує PHP? Наведіть приклади.**
  string - текст/рядок
  int - ціле число
  float - число з крапкою
  bool - так або ні

* **Що буде виведено в браузері, якщо користувач відкриє файл .html, всередині якого буде вбудовано <?php echo "Test"; ?> без налаштувань сервера? Поясніть чому.**
